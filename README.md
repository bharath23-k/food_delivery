# 🍔 Food Delivery Application

A modern and responsive Food Delivery Web Application that allows users to browse food items, add them to cart, and place orders seamlessly.

## 🚀 Features

- 🔐 User Authentication
- 🍕 Browse Food Categories
- 🛒 Add to Cart Functionality
- 💳 Order Placement
- 📱 Responsive Design
- ⚡ Fast and Interactive UI
- 🔎 Search Food Items
- ❤️ User Friendly Interface

## 🛠️ Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- React.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB
